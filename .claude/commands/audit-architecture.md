Задача:
Спроектировать архитектуру слоя аудита как встроенной части пайплайна.

Создай:
- `docs/04-architecture/audit-architecture.md`
- `docs/07-testing/audit-checklist.md`

Обязательные элементы:

1. **Два типа проверок:**
   - Детерминированные (всегда одинаковый результат)
   - Недетерминированные (через VLM, могут различаться)

2. **Детерминированные проверки включают:**
   - Вёрстка (границы, наложения, обрезания, выравнивание, пропорции)
   - Шаблон (шрифты, кегли, цвета, макеты, логотипы, контраст 4.5:1)
   - Плотность (буллеты, таблицы, диаграммы, заполнение)
   - Целостность (файл, заглушки, пустые слайды, дубликаты)

3. **Недетерминированные проверки:**
   - Валидация контента через VLM
   - Вопросы из Приложения 1 ТЗ
   - Формат ответа «да/нет» на изображение слайда

4. **Визуализация проблем:**
   - Красная подсветка — критические
   - Жёлтая — предупреждения
   - Синяя — рекомендации

5. **Интеграция в пайплайн:**
   - Аудит запускается после верстки, до экспорта
   - Пользователь может выбрать, какие проблемы исправить
   - После исправления аудит запускается повторно

Ограничения:
- Не писать код.
- Не менять другие слои архитектуры без согласования.
- Все расширения списка проверок фиксировать в ADR.
