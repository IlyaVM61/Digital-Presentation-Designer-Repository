Требования ТЗ к демо:

**Промежуточный этап:**
- Репозиторий с открытым доступом для экспертов
- End-to-end демонстрация: неизвестный шаблон + контент-пакет → готовая презентация
- 9 презентаций: 3 калибровочных шаблона (VK Tech, VK WorkSpace, VK Education) × 3 варианта, все на одном контент-пакете
- Видео-демо до 7 минут без монтажных склеек

**Обязательно в видео:** end-to-end прогон на шаблоне, которого нет в датасете и под который решение не настраивалось — любая презентация из открытых источников, лежащая в `assets/templates/acceptance/`. Живой прогон от загрузки файла до экспорта; заранее подготовленный результат не засчитывается. Это главное доказательство критерия оценки № 3 — что решение адаптируется к произвольному шаблону, а не работает по зашитым сценариям.

**Контент-пакет** — наш собственный артефакт (ТЗ: «контент-пакет (не представлен)»), один и тот же для всех девяти колод и для end-to-end прогона.

**Финальная сдача:**
- Зафиксированная версия репозитория
- Воспроизводимый сетап через конфиг-файл
- Три варианта верстки одной презентации

**Питч (до 7 минут):**
1. Проблема
2. Подход
3. Архитектура пайплайна
4. Живой демо-прогон
5. Архитектура аудита
6. Выводы
