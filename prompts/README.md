# Промпты

Промпты скиллов и агентов лежат здесь, а не в коде (ТЗ, п. 2.4). Код получает их через `dpd.llm.load_prompts()`; тест `tests/test_prompts.py` ищет промпты в исходниках `src/`, `ui/` и `scripts/` и падает, если находит.

## Формат файла

```markdown
---
name: response-repair
version: 1
purpose: зачем нужен промпт
placeholders:
  error: что подставляется вместо {error}
---
Текст промпта ровно в том виде, в каком он уйдёт модели. {error}
```

- `version` обязательна. Любая правка текста поднимает её.
- `placeholders` — подстановки вида `{имя}`: `Prompt.render(имя=…)` заменяет только объявленные, остальные фигурные скобки (например, пример JSON) остаются текстом.
- Ключ промпта — путь от этого каталога без расширения: `skills/response-repair`.
- Пустой файл — промпт, который ещё не написан. Загрузка его пропускает, обращение к нему — ошибка.

## Версия набора

Ведётся в `CHANGELOG.md`: первый заголовок `## ` — текущая версия. В `AuditReport.prompt_versions` попадают версия набора (`set`), версия каждого промпта и хеш содержимого (`digest`) — он выдаёт правку, сделанную без подъёма версии.
