# Журнал набора промптов

Версия набора — первый заголовок `## ` этого файла; она, версия каждого промпта и хеш содержимого попадают в `AuditReport` каждого прогона (T-48). Правка любого промпта поднимает его `version` в заголовке файла, новая версия набора записывается сюда сверху с перечнем изменённых промптов в виде `` `ключ` vN ``. Тест `tests/test_prompts.py` сверяет журнал с файлами.

## 9 — 2026-10-01

- `skills/content-validator` v1 — смысловые вопросы аудита текста о всей колоде одним запросом: заголовок-вывод, соответствие содержимого заголовку, одна мысль на слайд, утверждения без чисел вне фактуры, служебный текст, опечатки, лишние строки таблицы, связь с предыдущим слайдом. Каждое замечание-список — дословная цитата со слайда, это продублировано проверкой контракта ответа (T-51).
