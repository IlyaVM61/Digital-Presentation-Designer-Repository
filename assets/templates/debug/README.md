# Отладочные шаблоны

## Назначение

Здесь лежат шаблоны **не из датасета**, на которых уже отлаживали код. Универсальность они больше не доказывают — для этого есть `assets/templates/acceptance/`, — но остаются полезны как четвёртый шаблон для сборки «до и после» рядом с калибровочными.

Правило то же, что для калибровочных: **условий под конкретный шаблон в коде быть не должно** (правило 8 `CLAUDE.md`). Отлаживать на них можно, подстраиваться — нельзя.
