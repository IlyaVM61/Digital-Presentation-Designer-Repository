# Приёмочный шаблон

## Назначение

Здесь лежит шаблон, **которого нет в датасете** и под который решение не настраивалось. Он нужен, чтобы доказать главное свойство решения: пайплайн работает с произвольным шаблоном, а не по зашитым под три калибровочных файла сценариям.

Требование ТЗ к промежуточной сдаче: «демонстрация работы пайплайна end-to-end: на вход — неизвестный шаблон и контент-пакет, на выходе — готовая презентация». Требование к финальной защите: «на финальной защите презентации генерируются по шаблону, который команды не видели ранее».

**Прогон на этом шаблоне обязателен в видео-демо**, вживую и без склеек — от выбора файла до открытия экспортированного результата. См. `docs/07-testing/demo-scenarios.md`.

## Как выбирать шаблон

- Любая презентация из открытых источников.
- Формат `.pptx` или `.potx`.
- Не из семейства VK и не похожая по структуре на калибровочные — иначе демонстрация теряет смысл.
- Желательно с иной композиционной логикой, чем у калибровочных: другое соотношение сторон, другая типографика, другая система макетов. Чем дальше шаблон от датасета, тем убедительнее прогон.
- Не подбирать шаблон под возможности парсера. Если на нём что-то ломается — это находка, а не повод менять шаблон.

## Обязательно зафиксировать до записи видео

Для каждого файла в этой папке заполняется карточка ниже. Без неё шаблон не используется: комиссия должна видеть, что мы не взяли чужой корпоративный шаблон без оснований.

```text
Файл:
Источник (URL):
Дата загрузки:
Правообладатель:
Лицензия / условия использования:
Основание использования в демо:
```

### Карточки

**`Jessica · SlidesCarnival.pptx`**

```text
Файл:            Jessica · SlidesCarnival.pptx
Источник:        https://www.slidescarnival.com/template/jessica-free-presentation-template/14605
Категория:       Corporate
Дата загрузки:   2026-09-28
Правообладатель: SlidesCarnival (Jimena Landa)
Лицензия:        Creative Commons Attribution 4.0 International (CC BY 4.0)
Условия:         бесплатно для любого использования, включая коммерческое;
                 обязательна атрибуция; регистрация не требуется
Основание:       свободная лицензия, допускающая использование и переработку
                 при указании автора
```

### Обязательная атрибуция

CC BY 4.0 требует указания автора — это не пожелание, а условие лицензии. Атрибуция должна присутствовать там, где шаблон используется: в репозитории (этот файл) и в материалах защиты, где показывается результат прогона.

Текст атрибуции — использовать дословно:

> Шаблон презентации «Jessica» — SlidesCarnival (Jimena Landa),
> https://www.slidescarnival.com/template/jessica-free-presentation-template/14605
> Лицензия Creative Commons Attribution 4.0 International (CC BY 4.0).

Где эта атрибуция обязана присутствовать:

- [x] в этом файле репозитория;
- [ ] на слайде с результатом end-to-end прогона в видео-демо либо в его описании;
- [ ] в питч-презентации, если результат прогона показывается на слайде.

## Характеристики приёмочного шаблона

Результат проверки пригодности (не настройки под него):

| Параметр | Значение |
|---|---|
| Холст | 10.00 × 5.62″ (9144000 EMU) |
| Мастеров / макетов | 1 / 10 |
| Плейсхолдеров во всех макетах | 25, включая BODY, SUBTITLE, SLIDE_NUMBER |
| Слайдов-примеров | 39 |
| Шрифт по теме | Arial |
| Шрифты фактически | News Cycle (2385), Calibri (2295), Oswald, Montserrat, Arial |
| Встроенных шрифтов | 8 — рендер корректен без установки шрифтов в систему |
| Происхождение | экспорт из Google Slides: имена макетов в верхнем регистре, `docProps` отсутствует |

Шаблон независимо подтвердил вывод разбора калибровочного набора: тема объявляет `Arial`, фактически используется `News Cycle`. Расхождение темы с фактической разметкой — общее свойство реальных шаблонов, а не особенность шаблонов VK.

### Важное ограничение на использование этих данных

Разбор выше выполнен **только** для проверки пригодности шаблона. Его результаты не должны использоваться для настройки парсера, подбора эвристик или калибровки порогов — иначе шаблон перестанет быть приёмочным и прогон на нём потеряет доказательную силу. Настройка ведётся исключительно на калибровочном наборе.

## Что этот шаблон НЕ проверяет

Jessica — аккуратный, хорошо структурированный шаблон с настоящей плейсхолдерной разметкой. Он не покрывает главный выявленный риск: макеты, у которых есть только плейсхолдер заголовка, а весь контент размечен обычными фигурами (как во всех 15 макетах VK WorkSpace). Шаблон комиссии с большей вероятностью будет похож на второй случай.

Вопрос о добавлении второго, заведомо «грязного» корпоративного приёмочного шаблона отложен, см. вопрос T5 в `docs/00-input/open-questions.md`.

## Замечание о происхождении

«Из открытых источников» означает общедоступный и допускающий демонстрацию, а не просто найденный в интернете. Корпоративный шаблон постороннего бренда без явного разрешения на использование создаёт вопрос не к технике, а к добросовестности команды. Предпочтительны шаблоны под свободной лицензией либо официально опубликованные их правообладателем как общедоступные.

## Статус

Готов. Шаблон выбран, источник и лицензия зафиксированы, текст атрибуции подготовлен.

Остаётся выполнить атрибуцию в самих материалах защиты — в репозитории её недостаточно, если результат прогона показывается на экране.
