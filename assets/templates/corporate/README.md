# Корпоративные шаблоны второго хакатона

## Назначение

Материалы второго хакатона с близкой задачей — «ИИ-помощник для подготовки презентаций»: по исходному содержанию создать редактируемую презентацию по корпоративному шаблону. Организаторы выдают:

- корпоративный шаблон презентации;
- пример шаблона и инструкцию по именованию полей — вспомогательный пример для работы с полями шаблона.

Здесь лежат эти файлы. Для второго трека корпоративный шаблон — главный: его дают организаторы, искать «невиданный» шаблон, как в первом треке, не нужно.

## В репозитории их нет

Файлы выданы организаторами как рабочие материалы, разрешения на публикацию в открытом репозитории нет. `.gitignore` исключает из этого каталога всё, кроме README, — в каком бы формате файл ни пришёл.

**Правило добавлено раньше файлов, и порядок важен:** расширение VS Code GitDoc коммитит и отправляет в публичный репозиторий каждое сохранение сразу. Перед тем как класть сюда новый файл, стоит убедиться, что git его не видит: `git status --short assets/templates/corporate/` должен показывать пусто.

При переносе проекта на другую машину файлы кладутся сюда вручную.

## Файлы

Заполняется, когда файлы появятся: имя, что это (корпоративный шаблон, пример с полями, инструкция), откуда и когда получен.

```text
Файл:
Что это:
Источник:        организаторы второго хакатона
Дата получения:
Условия:         рабочие материалы, без публикации
```
