## Матрица девяти презентаций

Все девять генерируются из **одного и того же** контент-пакета `assets/content-pack/`. Различия порождаются только шаблоном и вариантом верстки — это и есть демонстрируемое свойство решения.

| | Вариант A | Вариант B | Вариант C |
|---|---|---|---|
| **VK Tech** | `vk-tech__a` | `vk-tech__b` | `vk-tech__c` |
| **VK WorkSpace** | `vk-workspace__a` | `vk-workspace__b` | `vk-workspace__c` |
| **VK Education** | `vk-education__a` | `vk-education__b` | `vk-education__c` |

Исходные шаблоны:

| Слаг | Файл | Холст |
|---|---|---|
| `vk-tech` | `VK Tech шаблон.pptx` | 10.00 × 5.63″ |
| `vk-workspace` | `VK_WorkSpace_Клиентская_конференция_Шаблон_03.pptx` | 13.33 × 7.50″ |
| `vk-education` | `Шаблон презентации VK Education.pptx` | 13.33 × 7.50″ |

Ось различий между вариантами A/B/C определяется на фазе 7, см. `docs/04-architecture/variants-strategy.md`.

### Схема размещения результатов

```text
out/
  decks/
    vk-tech__a.pptx        vk-tech__a.pdf        vk-tech__a.html
    vk-tech__b.pptx        ...
    ...
    vk-education__c.pptx   ...
  acceptance/
    external__a.pptx       результат end-to-end прогона на внешнем шаблоне
  audit/
    vk-tech__a.report.json отчёт аудита по каждой колоде
```

Каждая из девяти колод выгружается во все три формата, как требует ТЗ: `.pptx` (нативные объекты), `.html`, `.pdf`.

### Критерии приёмки девяти презентаций

- [ ] Все девять открываются без ошибок в PowerPoint
- [ ] В каждой 10–15 слайдов
- [ ] Каждая собрана на макетах своего шаблона, а не на произвольных фигурах
- [ ] Три варианта одного шаблона визуально различимы
- [ ] Ни один слайд не является растровым изображением целиком
- [ ] По каждой колоде есть отчёт аудита
- [ ] Генерация одной колоды укладывается в 5 минут

## End-to-end прогон на внешнем шаблоне

Отдельный артефакт, не входящий в девятку.

- Шаблон: любая презентация из открытых источников, которой нет в датасете и под которую решение не настраивалось. Лежит в `assets/templates/acceptance/`.
- Контент: тот же контент-пакет, что и у девяти колод.
- Результат: готовая презентация плюс отчёт аудита.
- Прогон обязательно попадает в видео вживую — от загрузки файла до экспорта.

Источник и лицензия внешнего шаблона фиксируются в `assets/templates/acceptance/README.md` до записи видео.
