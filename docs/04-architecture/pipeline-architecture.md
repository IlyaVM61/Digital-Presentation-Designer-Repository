# Архитектура пайплайна

## Обзор

Пайплайн состоит из 5 слоёв, как требуется в ТЗ. Этот документ детализирует корневой `ARCHITECTURE.md`.

## 5 слоёв

### Слой 1: Парсинг (Template Parser)

**Ответственность:** Превратить PPTX-файл в структурированное описание шаблона.

**Вход:** PPTX-файл.

**Выход:** `TemplateSchema` JSON.

**Компоненты:**
- `pptx-structure-extractor` — извлекает masters, layouts, placeholders
- `design-tokens-extractor` — извлекает цвета, шрифты, отступы
- `composition-patterns-detector` — определяет типовые композиции
- `visual-analyzer` (опционально, VLM) — находит паттерны, не выраженные в XML

**Контракты:**
- Вход: бинарный PPTX
- Выход: `TemplateSchema`

### Слой 2: Генерация (Content Generator)

**Ответственность:** Создать структуру и контент презентации по брифу.

**Вход:** Бриф, `TemplateSchema`, контент-пакет.

**Выход:** `PresentationStructure` JSON.

**Компоненты:**
- `brief-analyzer` — понимает цель и аудиторию
- `outline-generator` — создаёт последовательность слайдов
- `content-generator` — пишет текст для каждого слайда
- `visualization-planner` — планирует графики, таблицы, изображения

**Контракты:**
- Все LLM-ответы валидируются через JSON Schema
- При невалидном ответе — повторный запрос с уточнениями

### Слой 3: Верстка (Layout Engine)

**Ответственность:** Разместить контент в шаблонах с учётом правил.

**Вход:** `PresentationStructure`, `TemplateSchema`, `densityLevel`.

**Выход:** 3 варианта `RenderedPresentation`.

**Компоненты:**
- `layout-selector` — выбирает макет под контент
- `content-fitter` — размещает контент в слотах
- `overflow-handler` — обрабатывает переполнение
- `variants-generator` — создаёт 3 варианта по оси различий

**Контракты:**
- Детерминированный движок
- Все операции воспроизводимы

### Слой 4: Аудит (Audit Engine)

**Ответственность:** Проверить сгенерированную презентацию и выявить проблемы.

**Вход:** `RenderedPresentation`, `TemplateSchema`.

**Выход:** `AuditReport`.

**Компоненты:**
- `deterministic-auditor` — проверки вёрстки, шаблона, плотности, целостности
- `nondeterministic-auditor` — валидация контента через VLM
- `visualizer` — подсвечивает проблемы на слайдах
- `fix-recommender` — предлагает варианты исправления

**Контракты:**
- Детерминированные проверки всегда дают одинаковый результат
- Недетерминированные проверки помечаются как вероятностные

### Слой 5: Экспорт (Export Engine)

**Ответственность:** Выгрузить презентацию в требуемые форматы.

**Вход:** `RenderedPresentation`, прошедшая аудит.

**Выход:** .html, .pptx (нативные объекты), .pdf.

**Компоненты:**
- `html-exporter`
- `pptx-exporter` (обязательно нативные объекты!)
- `pdf-exporter`

**Контракты:**
- PPTX-экспорт не должен использовать растровые изображения для слайдов
- Все объекты должны быть редактируемыми в PowerPoint

## Оркестрация

Пайплайн может быть:
- **Синхронный** — для демо и небольших колод
- **Асинхронный** — для продакшена с очередями задач

## Версионирование

Промпты скиллов и агентов версионируются отдельно от кода. Каждому запуску пайплайна соответствует конкретная версия конфигов, что обеспечивает воспроизводимость.
